    <h1>World Food Prices Analysis Using Python Libraries</h1>

    <h2>1. Project Overview</h2>
    <p>
        The World Food Prices Analysis is an exploratory data analysis (EDA) and data science project developed using Python in Google Colab. The project analyzes historical and current global food price trends sourced from the World Bank Food Price Dataset. Using Python libraries such as Pandas, the project inspects, cleans, and evaluates food price metrics across multiple countries, dates, and market locations. It helps track food inflation dynamics and price movements over time to provide clear macroeconomic insights.
    </p>

    <h2>2. Project Objectives</h2>
    <ul>
        <li>To load, clean, and explore global food price data from the World Bank dataset.</li>
        <li>To inspect data dimensions, schema types, missing values, and statistical summaries using Pandas.</li>
        <li>To track trends in the target food price indicator (<code>Close</code>) across dates and geographical locations.</li>
        <li>To analyze food price inflation and its variations across different country markets.</li>
        <li>To examine currency distributions and their correlation with local commodity prices.</li>
        <li>To build a reproducible data workflow suitable for further visualization and modeling in Python.</li>
    </ul>

    <h2>3. Tools & Technologies Used</h2>
    <ul>
        <li><strong>Python:</strong> Primary programming language for data analysis.</li>
        <li><strong>Google Colab:</strong> Cloud-based interactive Jupyter notebook environment for development.</li>
        <li><strong>Pandas:</strong> Data wrangling, dataframe inspection (<code>head()</code>, <code>shape</code>, <code>info()</code>, <code>describe()</code>), and manipulation.</li>
        <li><strong>Matplotlib & Seaborn:</strong> Data visualization and statistical plotting.</li>
        <li><strong>CSV Dataset:</strong> Cleaned World Bank food price data file (<code>world_food_prices_cleaned.csv</code>).</li>
    </ul>
